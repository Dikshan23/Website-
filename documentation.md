# Legends Gym Website - Technical Documentation

## Overview
This is a modern, high-performance website built for **Legends Gym**. It features a premium "Dark Mode" aesthetic with neon accents, fully responsive design, and integrated lead generation.

### Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4, compiled with PostCSS.
- **UI Components**: Shadcn UI (Radix Primitives).
- **Backend & Database**: Supabase (PostgreSQL).
- **Payments**: Stripe (Checkout & Webhooks).
- **Email/Notifications**: SendGrid (Email), Sonner (Toast Notifications).
- **Language**: TypeScript.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17 or later.
- A Supabase project.
- A SendGrid account.
- A Stripe account.

### Installation
1.  **Clone the repository**:
    ```bash
    git clone <repository-url>
    cd gym-website
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Environment Setup**:
    ```bash
    cp .env.example .env.local
    ```
    The `.env.example` file is already pre-filled with the necessary test keys and configuration for immediate use. You will need to populate the Stripe keys:
    - `STRIPE_SECRET_KEY`
    - `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
    - `STRIPE_WEBHOOK_SECRET`

4.  **Database Setup**:
    Run the following SQL in your Supabase SQL Editor to create the submissions table:
    ```sql
    -- Contact Submissions Table
    create table contact_submissions (
      id bigint generated by default as identity primary key,
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      name text,
      email text,
      phone text,
      plan text,
      message text
    );

    -- Payments Table
    create table payments (
      id text primary key, -- Stripe Session ID
      created_at timestamp with time zone default timezone('utc'::text, now()) not null,
      customer_email text,
      amount integer, -- Stored in cents
      plan_id text,
      status text
    );
    ```

5.  **Run Development Server**:
    ```bash
    npm run dev
    ```
    Open [http://localhost:3000](http://localhost:3000) to view the site.

## 📂 Project Structure

- **`/app`**: Next.js App Router pages and API routes.
    - **`/api/contact`**: Serverless function handling form submissions.
- **`/components`**: React components.
    - **`/ui`**: Reusable UI components (buttons, inputs, etc.).
    - **`contact.tsx`**: Main contact form with validation and API integration.
- **`/lib` & `/utils`**: Helper functions and Supabase client configuration.

## ⚡ Key Features

### 1. Lead Generation System
The contact form is fully functional and performs two key actions on submission:
- **Database Storage**: Saves the lead details (Name, Phone, Email, Plan) to Supabase for permanent record keeping.
- **Instant Notification**: Uses SendGrid to send an email immediately to the gym owner.
    - **Smart Reply**: The "Reply-To" header is automatically set to the customer's email, so you can hit "Reply" and email them back instantly.

### 2. High-Performance Animations
Uses CSS-based animations and optimized transitions for a "premium" feel (fade-ins, slide-ups) without heavy JavaScript libraries, ensuring high Lighthouse scores.

### 3. Automated Revenue Collection (New)
Integrated Stripe Checkout for seamless membership purchasing.
- **Secure Payments**: Handled directly by Stripe (PCI compliant).
- **Instant Access**: Payment success instantly records the transaction in Supabase and sends a confirmation email to the user.

### 4. Responsive Design
Mobile-first approach. Tested on devices from iPhone SE to 4K Desktops.
- **Mobile**: Collapsible navigation, touch-friendly inputs.
- **Desktop**: Grid layouts, hover effects, parallax scrolling.

## 🛠 Deployment

This project is optimized for deployment on **Vercel**.

1.  Push code to GitHub.
2.  Import project into Vercel.
3.  Add the **Environment Variables** (from `.env.local`) to the Vercel Project Settings.
4.  Deploy.

## 🔄 Maintenance

- **Update Dependencies**: Run `npm update` regularly.
- **Database Customization**: You can add columns to the `contact_submissions` or `payments` table in Supabase if you want to collect more data.

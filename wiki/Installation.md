# Installation Guide

Follow these steps to set up the **Legends Gym** website locally.

## Prerequisites
Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.17 or higher)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)
- A **Supabase** account (for database)
- A **Stripe** account (for payments)
- A **SendGrid** account (for emails)

## Step-by-Step Setup

### 1. Clone the Repository
```bash
git clone https://github.com/Dikshan23/Website-.git
cd Website-
```
*(Note: Replace URL with your actual repo URL if different)*

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Configuration
Create a `.env.local` file in the root directory:
```bash
cp .env.example .env.local
```

Populate it with your secrets:
```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

# Stripe
STRIPE_SECRET_KEY=sk_test_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...

# SendGrid
SENDGRID_API_KEY=SG....
```

### 4. Database Setup (Supabase)
Run the following SQL in your Supabase SQL Editor:

```sql
-- Leads Table
create table contact_submissions (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text,
  email text,
  phone text,
  plan text,
  message text
);

-- Payments Table
create table payments (
  id text primary key, -- Stripe Session ID
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  customer_email text,
  amount integer,
  plan_id text,
  status text
);
```

### 5. Run Development Server
```bash
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) to see the app.

# Welcome to the Legends Gym Wiki

## Project Overview
**Legends Gym** is a modern, high-performance fitness website designed to attract new members and streamline business operations. Built with **Next.js 16**, **Tailwind CSS v4**, and **Supabase**, it combines a premium "Dark Mode" aesthetic with robust functionality.

## 🌟 Key Features
- **Lead Generation**: Seamless contact form integrated with **SendGrid** and **Supabase**.
- **Membership Payments**: Secure subscription checkout via **Stripe**.
- **Performance**: High-speed loading with optimized animations and SEO best practices.
- **Responsive Design**: Flawless experience across Mobile, Tablet, and Desktop.
